# 邻渡产品需求

## 第一版目标

在同一局域网内的 Windows 与 macOS 设备之间，单对单传输普通文字、链接、单个文件和多个文件。应用不依赖公网服务器或账号系统。

## 范围

第一版包括手动 IP/端口连接、连接审批、设备信息、文字与文件传输、接受/拒绝、进度、速度、取消、重试、本地历史、设置以及 Windows/macOS 测试包。

产品名称为「邻渡」，含义是让相邻设备之间的内容安全、直接地渡达。界面支持浅色与深色模式；历史记录支持按内容、文件名、设备名称或 IP 搜索。

第一版不包括自动发现、公网中继、账号、文件夹、断点续传、自动剪贴板同步、端到端加密、二维码、自动更新、开机启动、移动端或群发。

## 1.1 增强范围

用户已单独确认在第一版完成后增加局域网自动发现。1.1 使用 UDP 组播显示同网段在线设备，保留手动 IP/端口作为防火墙、访客网络或组播不可用时的回退；自动发现不代表信任，连接仍走既有陌生设备审批和单对单约束。

1.1 同时增加文件传输防休眠、活动任务退出确认、预计剩余时间和接收完成后的系统文件定位。仍不增加公网中继、账号、文件夹、断点续传、自动剪贴板同步、端到端加密、二维码、自动更新、开机启动、移动端或群发。

完整验收范围以已确认的阶段 1 计划为准。
